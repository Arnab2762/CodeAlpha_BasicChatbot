# CodeAlpha_BasicChatbot
# 🤖 Basic Chatbot Using Python

A simple rule-based chatbot developed using Python as part of my CodeAlpha Python Internship.

The chatbot interacts with users through the terminal and provides predefined responses based on their messages.

## 🎯 Project Objective

The objective of this project is to build a basic conversational program using Python fundamentals.

## ✨ Features

- Interactive text-based conversation
- Predefined responses to user messages
- Supports greetings such as "hello" and "hi"
- Responds to questions such as "how are you"
- Handles unknown messages
- Continues the conversation until the user types "bye"

## 🛠️ Technologies Used

- Python
- Functions
- Conditional statements (`if-elif-else`)
- `while` loops
- String manipulation
- User input and output
